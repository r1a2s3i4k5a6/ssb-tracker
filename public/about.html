About this project

A Web Technology project by Rasika R, BCA, Sastra Deemed University.

What it does

SERVICE SELECTION BOARD TRACKERhelps defence aspirants prepare every day. They plan a schedule, tick off tasks, keep a streak, earn ranks and badges, practise the WAT, TAT and OIR tests, and see their progress in charts.

How it is built

  • Front end: HTML, CSS and JavaScript with no frameworks. Charts are drawn as SVG.
  • Back end: Node.js with Express, using sessions for login.
  • Database: SQLite with 6 linked tables: aspirants, tasks, completions, quiz questions, quiz attempts and messages.
  • Security: passwords are hashed with bcrypt, every private route checks the login, and the server marks the quizzes.

An independent student project. It is not affiliated with the Services Selection Board or the Indian Armed Forces.
